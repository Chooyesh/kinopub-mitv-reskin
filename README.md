## Что это

Перекомпилированный официальный клиент KinoPub для Android TV (база 1.34 beta4)
с заменённым интерфейсным слоем: главные экраны (каталог фильмов/сериалов, поиск,
«Мои», карточка фильма/сериала) перерисованы в стиле клиента для Apple TV (tvOS).
Вся логика воспроизведения, настроек, активации устройства и работы с данными —
оригинального приложения, она не изменялась.

**В репозитории не публикуются исходные коды** — ни оригинального приложения, ни модификации:
только готовая сборка и это описание. Это осознанный выбор из уважения к труду
разработчиков оригинального клиента.

## Что изменено по сравнению с оригинальным клиентом

- Главный экран в стиле tvOS: верхние вкладки (Поиск / Фильмы / Сериалы / Мои / ТВ / Настройки),
  hero-карусель с автопрокруткой, горизонтальные ряды постеров (новинки, популярное, горячее, 4K).
- Поиск: нативная клавиатура телевизора, результаты по мере набора, разделение на фильмы/сериалы.
- «Мои»: «Я смотрю» (только сериалы с галочкой «буду смотреть», со счётчиками непросмотренных серий),
  история просмотров, папки закладок с полной загрузкой содержимого.
- Карточка фильма/сериала в формате tvOS: заголовок по центру, режиссёр и актёры слева,
  метаданные и чипы (качество/звук/субтитры), описание, кнопки действий с иконками,
  постер справа; ниже — оценки (KinoPub / IMDb / Кинопоиск), общая информация, рекомендуемое.
- Навигация с пульта (D-pad) по всему интерфейсу, пошаговый «Назад», возврат из карточки
  на то место, откуда она была открыта.
- Пакет `com.kinopub.mitv` — устанавливается параллельно с официальным клиентом и не затрагивает его.

Не изменено: плеер, активация устройства, настройки, ТВ-каналы, закладки/история на стороне сервиса.

## Установка

1. Разрешите на телевизоре установку из неизвестных источников.
2. Установите APK (поверх предыдущих версий MITV — как обновление; официальный клиент не затрагивается).
3. При первом запуске — активация устройства, как в оригинальном приложении
   (требуется действующий аккаунт/подписка сервиса).
4. Если ваш провайдер блокирует домены сервиса — добавьте пакет `com.kinopub.mitv`
   в проксируемые (например, в v2raytun).
